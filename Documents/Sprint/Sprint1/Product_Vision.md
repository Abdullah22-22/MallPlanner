# MallPlanner – Product Vision

## Problem Statement

Small investors, building owners, and mall managers often need an initial estimate of how the available space in a shopping mall can be divided between shops and other services. Without a simple planning tool, these calculations may be done manually or may require professional consultation at an early stage.

MallPlanner provides a simple way to estimate usable shop space and potential profit before investing in a detailed architectural plan or professional feasibility study.

## Target Audience

MallPlanner is designed mainly for:

- Small investors who are considering a shopping mall project.
- Building owners who want to understand how their available space could be used.
- Mall managers who need a quick estimate of rentable space and potential income.

The application is intended for users who want a simple first estimate before consulting architects or other professionals.

## Value Proposition

MallPlanner provides a simple and practical way to calculate how shopping mall space can be divided and how much income each floor could generate.

Instead of manually calculating the available space, the user can enter basic information about the building and floor areas. The application automatically calculates the remaining space for shops and updates the results when shops are added, edited, or removed.

It also helps the user compare floors and gives suggestions for using remaining free space. This allows the user to quickly explore different possibilities before spending money on professional planning.

## Key Features and Functionality

- Enter basic building information, such as the building name, number of floors, floor areas, rent price, and costs.
- Define bathrooms, restaurants, lounge areas, corridors, and service areas for each floor.
- Automatically calculate the remaining rentable space available for shops.
- Add, edit, and delete shops.
- Prevent shops from being added when there is not enough available space.
- Show how much additional space would be required when a shop is too large.
- Suggest possible ways to use remaining free space.
- Calculate income, costs, and net profit for each floor.
- Compare floors and identify the most profitable floor.
- Provide both English and Finnish language support.
- Start with a console-based application and later provide a JavaFX user interface.

## Goals and Objectives

The main goals of MallPlanner are to:

- Correctly calculate the space available for shops after other required areas are deducted.
- Provide accurate income, cost, and profit calculations for each floor.
- Update calculations when shops are added, edited, or deleted.
- Validate user input and prevent invalid information from being saved.
- Provide useful suggestions for remaining free space.
- Make the application simple enough for a new user to understand without additional explanation.
- Implement the same core business logic for both the console and JavaFX versions.
- Support both English and Finnish.
- Complete the planned functionality within the project schedule.

The project will be considered successful when the calculations work correctly, invalid input is handled properly, the required functionality works in both the console and JavaFX versions, and a new user can use the application without additional guidance.

## Vision Statement

Our vision is to create a simple and practical shopping mall planning tool that helps small investors, building owners, and mall managers quickly estimate how mall space can be used and how much income different floors could generate.

MallPlanner aims to provide a useful first estimate before users invest time and money in professional architectural planning or a detailed feasibility study.

The application is a space calculator and profit analysis tool. It does not create architectural floor plans, decide the physical placement of individual shops, or manage tenants and contracts.
